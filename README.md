## 🚄 Shinkansen Passenger Experience Analysis

**Predictive Machine Learning · CatBoost · Optuna · Feature Engineering**

Built and optimized classification models to predict Shinkansen passenger satisfaction, combining extensive feature engineering with advanced boosting models and hyperparameter optimization.

**Current documented result:** **0.9597 Accuracy · 0.9943 ROC AUC** using tuned CatBoost.

**Business Machine Learning · XGBoost · Lead Scoring · Feature Engineering**

## 🛒 Amazon Product Recommendation Engine

**Recommendation Systems · Collaborative Filtering · SVD**

Developed and compared recommendation approaches on a dataset containing approximately **7.8 million ratings**, including rank-based recommendations, collaborative filtering, and matrix factorization.

**Current documented result:** Optimized SVD achieved **RMSE 0.8808**.

[View Repository](https://github.com/GC2407CIZV/Projects/tree/main/Amazon%20Product%20Recommendation%20Engine)

## 🦆 Quacktastic Conundrum

**Harvard CS50 Final Project · Full-Stack Development · Flask · SQLite · JavaScript**

Designed and implemented a state-driven browser mystery game in which players investigate interconnected fictional environments to recover Harvard's missing rubber duck mascot.

The application combines authentication, persistent clue progression, prerequisite-based unlocking, gated environments, simulated social platforms with in-game authentication, contextual hints, gameplay timing, ranking, and custom JavaScript interactions.

[View Repository](https://github.com/GC2407CIZV/Projects/tree/main/Quactastic%20Conundrum) · [Watch Demo](https://www.youtube.com/watch?v=M8YOX5bFVbg)
